Diwali Sales Analysis

Optimizing Festive Sales through EDA (Python)

Python Pandas Seaborn Visualization

Project Overview

Conducted extensive Exploratory Data Analysis (EDA) on a festive season sales dataset to identify key demographics and purchasing patterns. This project helped reveal that female customers aged 26-35 are the highest contributors to revenue during Diwali.

Analysis Highlights

[Interactive Chart: Sales by State & Gender]
  • 🔹 Data Cleaning: Handled null values and optimized data types for processing.
  • 🔹 Demographic Insight: Analyzed spending patterns across different professions and states.
  • 🔹 Product Performance: Identified top-selling categories (Food, Clothing, Electronics).

Key Findings
