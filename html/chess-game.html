    Project Overview

    Designed and developed by **Ishant Raj**, this pro-grade Chess engine features a sophisticated Negamax algorithm with Alpha-Beta pruning. It provides a challenging AI experience with multiple difficulty levels and a complete set of game management tools.

    Engine Architecture

    • 🧠 **Strategic AI**: Hard mode utilizes a 2-ply Negamax recursive search for deep positional evaluation.
    • 📅 **Move Management**: Complete history tracking with Undo/Redo support and PGN export.
    • ♟️ **Unicode Rendering**: High-performance rendering using semantic chess glyphs for zero-latency UI updates.
    • ⏲️ **Blitz Timing**: Integrated countdown timers for competitive competitive play simulation.

    Technical Stack

    Deep algorithmic implementation focused on game theory and search optimization.
