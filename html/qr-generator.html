Project Overview

Inspired by the Python implementation in **Qr.py**, this web-based version provides a fast, client-side solution for generating high-quality QR codes. It allows users to convert any string or link into a scannable code instantly.

Technical Capabilities

  • ⚡ **Real-time Generation**: QR code updates as you type (debounced).
  • 💾 **Export Support**: High-resolution image download functionality.
  • 🔒 **Privacy First**: All processing is done locally in your browser.
  • 🎨 **Custom Scaling**: Optimized for both small and large display formats.

A utility-focused application demonstrating DOM manipulation and script integration.
