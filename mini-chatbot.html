Project Overview

Mini ChatBoat is a sophisticated virtual assistant that combines local logic with powerful large language models. It leverages the **Google Gemini Pro API** to provide intelligent and context-aware responses to complex queries.

Advanced Technical Features

  • 🧠 **Generative AI**: Seamless integration with Gemini 1.5 Flash.
  • 💻 **Coding Engine**: Built-in regex detection for programming syntax.
  • 📊 **Math.js Integration**: Local evaluation for high-speed mathematical operations.
  • ✨ **Dynamic Formatting**: Automatic Markdown and code-block rendering.

Technical Stack

Developed using modern JavaScript architecture with a focus on asynchronous state management and clean UI rendering.
