Project Overview

This application allows users to find geographical locations in India by entering a 6-digit PIN code. It fetches real-time data using the Nominatim OpenStreetMap API and visualizes it using Leaflet.js.

Core Functionality

  • 📍 Dynamic PIN code validation
  • 🗺️ Interactive Map with precise markers
  • 🌐 Real-time address resolution via API
  • ⚡ Minimalistic and fast user experience

Dev Notes

Built as a lightweight utility tool. The logic focuses on asynchronous data handling and clean UI updates without page reloads. Perfect for logistics or user-address verification scenarios.
