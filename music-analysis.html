Music Store Data Analysis

Uncovering growth opportunities through Advanced SQL Querying

SQL PostgreSQL Business Intelligence

Project Overview

This project involved analyzing a large dataset from a digital music store to identify customer behavior patterns, popular genres, and regional sales performance. The goal was to provide actionable business insights for stock optimization and marketing strategy.

Key Objectives

  • ✅ Identify the top-selling genres in each country.
  • ✅ Determine the most valuable customers based on lifetime purchase value.
  • ✅ Analyze the correlation between playlist size and track popularity.

Advanced Analysis Snippet

Using Common Table Expressions (CTEs) and Window Functions to find the most popular music genre by country:

WITH popular_genre AS ( SELECT COUNT(invoice_line.quantity) AS purchase_count, customer.country, genre.name, genre.genre_id, ROW_NUMBER() OVER(PARTITION BY customer.country ORDER BY COUNT(invoice_line.quantity) DESC) AS RowNo FROM invoice_line JOIN invoice ON invoice.invoice_id = invoice_line.invoice_id JOIN customer ON customer.customer_id = invoice.customer_id JOIN track ON track.track_id = invoice_line.track_id JOIN genre ON genre.genre_id = track.genre_id GROUP BY 2,3,4 ORDER BY 2 ASC, 1 DESC ) SELECT * FROM popular_genre WHERE RowNo <= 1;
