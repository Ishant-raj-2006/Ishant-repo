Project Overview

Designed and developed a real-time student ranking system for the **Ignite Club - BugByte**. This platform allows students to track their progress, points, and standings within the VGI institution community.

Core Features

  • 🏆 **Dynamic Ranking**: Automatic sorting based on points earned in club activities.
  • 🔍 **Instant Search**: Optimized roll-number based filtering for quick lookups.
  • 🔗 **Social Connectivity**: One-click access to student LinkedIn and GitHub profiles.
  • 🎭 **Interactive UX**: Cinematic welcome screen with speech synthesis integration.

Technical Stack

A lightweight, front-end heavy implementation focused on performance and clear data visualization.
